# QtKnight

基于 Qt 6.12 和 C++17 的横版闯关游戏项目。当前仓库处于接口定义阶段，用于两人并行开发时统一数据结构、模块边界和函数签名。

接手项目或开启新会话时，请先读[项目交接说明](HANDOFF.md)，再按其中的顺序阅读架构与接口文档。

## 当前内容

- `src/contracts/KnightContracts.h`：跨模块共用的枚举、结构体和结果类型。
- `src/game/KnightGame.h`：界面调用业务层的公开接口。
- `src/state`、`src/map`、`src/motion`、`src/combat`、`src/ai`、`src/content`、`src/save`：底层模块的公开接口；需要保存内部状态的模块另有 `*Private.h`。
- `docs`：架构、接口与业务数据流文档及配图。
- 根目录 `CMakeLists.txt`：当前构建配置。

## 开发状态

现阶段只定义接口，**不能运行完整游戏**。`KnightState.dll` 中保留了之前的三个演示函数；其他公开函数尚未实现，也未加入构建。后续开发应先按[模块及接口设置](docs/模块及接口设置.md)实现函数，再按[业务逻辑与数据流](docs/业务逻辑与数据流.md)接入业务层。

每个底层模块只能依赖共享契约，不能直接调用其他底层模块。业务层负责按顺序调用底层接口并传递结果。所有模块须使用相同的编译器、架构和构建配置；本项目计划使用 Qt 6.12 的 MSVC2022 64 位套件。
