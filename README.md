# Qt Knight

Qt Knight 是一套面向 Windows 的 C++17 / Qt 6 单机游戏源码。头文件定义游戏对象和模块接口，对应的 `.cpp` 文件预留实现位置。

在 Visual Studio 中选择「打开本地文件夹」，即可浏览仓库里的头文件和源文件。

## 源码目录

| 目录 | 职责 |
| --- | --- |
| `datamanagelib` | 定义角色、地图对象、关卡配置和存档数据。 |
| `algorithmlib` | 声明运动、碰撞、攻击判定和敌人决策规则。 |
| `maplib` | 声明关卡文件的读取与校验接口。 |
| `servicelib` | 组织游戏会话、固定步更新、关卡切换和进度写入。 |
| `visuallib` | 定义分层渲染与音效反馈接口。 |
| `QtKnightApp` | 定义主窗口和游戏画布，接收输入并转交游戏会话。 |
